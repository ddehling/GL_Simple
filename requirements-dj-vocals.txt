# OPTIONAL: ML vocal detection for the DJ library scanner.
#
# The scanner works without these - tracks just get no vocal
# measurements (vocalness 0.0, no vocal/instrumental tags). With them,
# scans run a second pass that separates each track's vocal stem
# (Demucs htdemucs) and stores real per-section vocal presence.
#
# Deliberately NOT in requirements.txt: torch is heavy and useless on
# the Raspberry Pi image-display installs. Install on DJ machines only.
#
# WITH AN NVIDIA GPU (any DJ show machine should use this - the vocal
# pass runs ~10-30x faster; lib/dj/vocals.py auto-detects CUDA):
#
#   pip install torch --index-url https://download.pytorch.org/whl/cu126
#   pip install -r requirements-dj-vocals.txt
#
# CPU-only machines:
#
#   pip install torch --index-url https://download.pytorch.org/whl/cpu
#   pip install -r requirements-dj-vocals.txt
torch
demucs
# the drum-kit decomposition (lib/dj/drumsep.py) fetches its 167 MB checkpoint into models/ on first use
gdown
# basic-pitch (the `other` stem's transcription) on the GPU: 3-7x faster than the CPU provider, identical notes
# (verified 2026-09-09); needs the CUDA 12 torch build above so the cuDNN DLLs are on the path - import torch first
onnxruntime-gpu
