# Optional backends for the generative music subsystem (lib/gen).
# The numpy/numba analog rack needs nothing beyond requirements.txt.
#
#   SoundFont instruments (lib/gen/synth/fluid.py):
#     pip install -r requirements-gen.txt
#     Debian/Ubuntu: sudo apt install fluidsynth libfluidsynth3 fluid-soundfont-gm
#     (-> /usr/share/sounds/sf2/FluidR3_GM.sf2; or put an .sf2 in media/soundfonts/)
#     Windows: unzip fluidsynth-vX-win10-x64-cpp11.zip (github.com/FluidSynth/fluidsynth/releases)
#     to C:\tools\fluidsynth  (pyfluidsynth looks in C:\tools\fluidsynth\bin by itself) and put
#     FluidR3 GM (ftp.osuosl.org/pub/musescore/soundfont/fluid-soundfont.tar.gz) at
#     media/soundfonts/default.sf2 (gitignored).
#   Strudel patterns (lib/gen/composer/strudel.py): runs IN-PROCESS via an
#   embedded V8 (mini-racer) with the committed bundle - no node needed.
#   (Node fallback / rebuilding the bundle: node >= 18, cd tools/gen/strudel
#   && npm install, ./build_bundle.sh)
#   SuperCollider backend (lib/gen/backends/sc.py):
#     Debian/Ubuntu: sudo apt install supercollider-server sc3-plugins
#     Windows/macOS: the SuperCollider installer provides scsynth. Without admin rights on Windows,
#     unzip SuperCollider-X-win64.zip (github.com/supercollider/supercollider/releases) to
#     C:\tools\SuperCollider and add that folder to the user PATH (supriya searches PATH and
#     C:\Program Files\SuperCollider*; or set SUPRIYA_SERVER_EXECUTABLE to scsynth.exe).
